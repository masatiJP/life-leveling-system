# Как выложить лендинг + приложение на GitHub Pages

## Структура репозитория
Положи в корень репозитория (или в отдельную ветку `gh-pages`) все эти файлы рядом, без вложенных папок:

```
index.html              ← лендинг (открывается по умолчанию на домене)
lls-app.html             ← само приложение (PWA)
manifest.json
sw.js
icon-192.png
icon-512.png
icon-512-maskable.png
```

Имя `index.html` важно только для лендинга — GitHub Pages отдаёт именно его на корневой адрес сайта (`https://ваш-ник.github.io/репозиторий/`). Само приложение при этом открывается по адресу `.../lls-app.html`, и это не мешает его установке как PWA — установка привязана не к имени файла, а к тому, что на странице подключён `manifest.json` и зарегистрирован `sw.js`.

## Как это работает вместе
1. Человек открывает сайт → видит лендинг (`index.html`).
2. Жмёт «Открыть приложение» → переходит на `lls-app.html`, это тот же домен.
3. На этой странице в Настройках появляется кнопка «Установить»:
   - на Android/десктопном Chrome — ставит приложение в один тап;
   - на iPhone (Safari) — показывает инструкцию «Поделиться → На экран Домой», потому что Apple не разрешает сайтам предлагать установку напрямую, только через меню самого Safari.

## Шаги публикации
1. Создай репозиторий на GitHub, залей туда все файлы списком выше.
2. В настройках репозитория включи **Settings → Pages**, источник — ветка с файлами, папка `/root`.
3. Через пару минут сайт будет доступен по адресу вида `https://ваш-ник.github.io/название-репозитория/`.
4. Открой этот адрес на телефоне и проверь, что кнопка «Установить» в Настройках приложения работает.

## На будущее (когда понадобится синхронизация между устройствами)
Сейчас все данные хранятся в `localStorage` браузера — только на этом устройстве.
Когда решишь добавить аккаунт и синхронизацию:
- в приложении уже есть кнопки **«Экспорт»** и **«Импорт»** в Настройках — готовый формат JSON, который потом можно будет отправлять на свой backend без переделки структуры;
- `sw.js` уже содержит место для обработчика `push`, когда появится сервер, который сможет слать настоящие уведомления (сейчас работает только локальное напоминание, пока вкладка открыта).

## Не забыть
Иконки интерфейса взяты с game-icons.net (Lorc, Delapouite, Skoll, Carl Olsen) под лицензией CC BY 3.0 — она требует указания авторства. В самом интерфейсе эта строка убрана по твоей просьбе, так что атрибуцию нужно добавить в `README.md` репозитория перед тем, как делать его публичным.
